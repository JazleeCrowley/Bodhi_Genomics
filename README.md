#Barcode Analysis
My first study is a genetic, barcode analysis of Ficus religiosa spread across the globe. This was done primarily through Sanger sequencing.

[Here](./figures/chord_diagram.png) you will find a diagram visualizing where the different population haplotype frequencies are occurring across the globe, according to my current findings. [This](./figures/barcode_analysis.r) is the code that generated the diagram.
